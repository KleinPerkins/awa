source chain and explicit administrator-exception classification. Do not arm

Immediately re-read and bind admission to repository id, PR number/state, head,
base ref/SHA, changed files, patch/tree, complete reviews/conversation resolution,

changed/missing/ambiguous inputs. The merge request uses `merge_method=squash`

and requires investigation, not force-push repair.

**Exit:** exact reviewed maintenance merge, sealed ref, complete audit chain.
**Recovery:** no destructive rollback; retain branch and fix forward only under
